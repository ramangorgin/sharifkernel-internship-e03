# Kurdish AI — Landing Page

A responsive, static concept landing page for Kurdish AI, an early-stage vision for AI-powered Sorani Kurdish language technology.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive layout, visual design, and animations
- `script.js` — preloader, mobile navigation, icon initialization, and scroll reveals

## Run locally

Open `index.html` in a browser, or serve the folder with a local static server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000> from this folder.

## External assets

The page uses Google Fonts (DM Sans and Manrope) and Lucide icons from unpkg. An internet connection is required for those assets; the page layout and content remain usable if they are unavailable.

## Status

This is a concept presentation. The features shown are future product directions, not currently available services.
